# 수행평가 일람표 개인별 성적 확인표 출력 시스템 (NEIS 호환)

나이스(NEIS)에서 내려받은 **수행평가 일람표 PDF, Excel, CSV** 파일을 업로드하면, 학생 개인별로 영역별 점수와 총점을 확인하고 **A4 용지 1장에 여러 명(2~4명)의 성적 확인표를 절취선(✂)과 함께 깔끔하게 일괄 출력**할 수 있는 웹 애플리케이션입니다.

## ✨ 주요 기능
- **다양한 파일 포맷 지원**:
  - 나이스(NEIS) 수행평가 강의실별/학급별 일람표 **PDF 자동 파싱** (평가 영역명, 만점, 반영비율, 학생별 점수, 총점, 메타데이터 자동 추출)
  - 엑셀(.xlsx, .xls) 및 CSV 일람표 파일 스마트 헤더 감지 및 파싱
- **학생 개인별 성적 확인표 (A4 최적화)**:
  - 한 페이지당 학생 수 선택 가능 (1장에 3명 권장 / 2명 / 4명)
  - 학생과 학생 사이에 명확한 **절취선 (✂ 자르는 선)** 표시
  - 학생 확인 서명란, 보호자 확인 서명란, 교사 확인란 선택적 포함
  - 이의신청 기간 및 학교 안내 문구 커스텀 기능
- **전체 학생 성적 조회 & 통계**:
  - 실시간 학생 이름/번호 검색 및 정렬 (번호순, 총점순, 이름순)
  - 학급 통계 요약 (응시 인원, 학급 평균, 최고 득점, 최저 득점)
  - 인쇄할 학생 선택/전체 선택 기능
- **100% 로컬 보안 처리**:
  - 학생의 성적 및 개인정보는 외부 서버나 데이터베이스로 전송되지 않고 오직 사용자의 브라우저 내에서만 안전하게 처리됩니다.

## 🚀 빠른 시작 (로컬 실행)
```bash
# 의존성 설치
npm install

# 로컬 개발 서버 실행
npm run dev

# 프로덕션 빌드
npm run build
```

## 🖨️ A4 인쇄 가이드
1. 상단 또는 본문의 **[A4 인쇄하기]** 버튼 클릭 (단축키: `Ctrl + P`)
2. 인쇄 옵션 확인:
   - 대상: 프린터 또는 **PDF로 저장**
   - 용지 크기: **A4**
   - 방향: **세로 (Portrait)**
   - **배경 그래픽**: 체크 (테이블 헤더 배경색 및 배지가 선명하게 인쇄됩니다)
   - 머리글/바닥글: 체크 해제 권장
